# Sanctions Review Desk design system

Sanctions Review Desk is an evidence-led case workspace for first-line analysts and quality-control reviewers. It should feel credible beside enterprise screening software while remaining clearly identifiable as an independent training work sample.

## Direction

- Light operational workspace with a deep navy case rail.
- Teal communicates selection and progress; blue communicates actions; amber marks unresolved review state.
- Public Sans supports dense case information without turning the interface into a developer console.
- Hierarchy comes from the persistent rail, stage navigation, tables and evidence registers rather than decorative cards.

## Interaction rules

- All controls provide a minimum 44px target and visible focus.
- A possible match is never presented as a final finding.
- Training, analyst-entered and external-source information remain visibly labeled.
- QC state is attached to a preserved submission, not the mutable analyst draft.

## Layout

- Desktop keeps case selection persistent beside the investigation.
- Mobile collapses the rail into a compact case chooser and stacks evidence before assessment controls.
- Tables may scroll horizontally; the page itself must not.
